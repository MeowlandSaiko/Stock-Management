# Stock-Management
アルバイトをしていて、企業管理システムの自作を思いついた。まずは、在庫管理システムから作っていきたいと思う。フィリピンの祖母がサリサリストアを経営している。効率が悪いため俺がIT化を進める。

**最終的な目標**

企業システムである在庫管理システム、販売管理（POS)、顧客管理（CRM）、受注管理システム、会計システム、勤怠管理、人事システムを作りあげ、AIを導入することである。これをおれの祖母がフィリピンで営んでいるサリサリストアで導入するし祖母の店の生産性をハイテクにする。

**最初の一歩**

まずは、企業システムの中の１つである。在庫管理システムの構築から行っていきたいと思う。在庫管理システムを細分化するとあらに４つに分けられる。以下の通りになる。
１，商品管理
２，在庫管理
３，売上管理
４，発注管理
おれは、まず、商品管理システムを作ることから始める。

想定している構成：

フロントエンドーHTML（入力フォーム）、CSS（画面デザイン）、JavaScript（ボタン操作）、Python（登録処理）、SQL（データベースへの保存）、MariaDB（データ管理）

**（用意するもの）**

ハードウェア：

ノートPC、自宅サーバー、インターネット環境

ソフトウェア：

Ubuntu,FastAPI、Python3、MariaDB、HTML、CSS、JavaScript,Nginx、Docker、Git,GitHub,VS Code
